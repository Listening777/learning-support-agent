## 一、报价总览（三档方案）

| 方案 | 定位 | 核心范围 | 周期 | 总报价 |
|---|---|---|---|---|
| **低配版** | 可用 MVP | RAG 制度问答 + 预约工具链 + 学生确认 + 基础管理后台（知识库） | 3 周 | **¥28,000** |
| **中配版（推荐）** | 完整交付 | 低配 + 提示词热更新 + 对话审计/风险标记 + 心理危机转人工 + 评测与上线检查 | 5 周 | **¥56,000** |
| **高配版** | 规模化试点 | 中配 + 学业预警联动 + 多租户 SaaS 化 + PostgreSQL 迁移 + CI/CD 与监控告警 | 10 周 | **¥128,000** |

> 推荐理由：中配版覆盖老师交付清单的全部合规要求（至少 3 处人工确认/审核点、风险转人工、上线手册），性价比最高，适合单校试点。

## 五、报价边界与说明

1. 报价含开发、测试、部署、文档与 1 个月试运行支持；不含校内网络改造与硬件采购；
2. 超范围需求（如对接教务系统 API、定制报表）按 ¥1,200/人日另行评估；
3. LLM 调用费与校并发规模强相关：日均 2,000 次问答内按上表，超量按实际用量调增；
4. 三档均可后期升级：低配→中配补差 ¥30,000（±10%），中配→高配补差 ¥76,000（±10%）；
5. 本报价为课程项目演示口径，正式商务报价需以立项调研为准。
