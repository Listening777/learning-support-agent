## 核心发现（详见 discovery-report.md）

- **[P0] 求助识别与交接环节是漏单和响应超时的主要瓶颈**：每周约 900 条、单条约 6 分钟，首次响应 26h 远高于 8h 目标，重复求助率 35% 高于 15% 目标。
- **[P0] 交接完成须以接手人确认为准**：关键说明散落个人便签与群聊，「已转交」无法证明完成。
- **[P0] 建议须可回溯到原记录与资料版本**：异常暂停而非覆盖，审计可重建处理链。
- **[P1] 数据口径与接口治理先于自动推荐上线**：补交/撤回缺统一编号，LMS 等权限独立。

约束红线：不自动给学生定性或评分；建议须附行为证据；异常转人工并留痕；错误结果不得覆盖原记录。
