## 三、快速部署步骤（5 步）

1. `pip install fastapi uvicorn jieba numpy faiss-cpu`
2. 解压仓库，进入 `src/`
3. `python -m uvicorn learning_support.main:app --port 8000`（首启自动建库建表、初始化管理员与风险规则）
4. 管理端登录 → 知识库页上传 `data/policy/学习支持与辅导协作管理制度.md`（自动切片为 7 块并建索引）
5. 访问 /api/health 确认存活，学生端 /chat 开始问答
