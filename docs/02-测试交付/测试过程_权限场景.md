# 测试过程 · 权限场景

> 场景：RBAC 角色守卫（student/admin）与 Token 有效性校验。
> 数据：tests/metrics/metrics_permission.json · 图表：chart_权限.png

## 一、被测机制

- JWT（HS256）鉴权：Authorization: Bearer \<token\>，无效/伪造 Token 一律 401 + code 4011
- 角色守卫（routes.py:46/56）：管理接口 require_admin → 学生访问返回 code 4012「需要管理员权限」

## 二、执行步骤与实测记录

| # | 场景 | 请求 | 实测返回 | 判定 |
|---|---|---|---|---|
| D1 | 学生访问管理统计 | GET /api/admin/stats（学生 Token） | HTTP 200 + `{"code":4012,"message":"需要管理员权限"}` | ✔ |
| D2 | 无 Token 访问管理接口 | GET /api/admin/stats（无头） | HTTP 401 + `{"code":4011,"message":"请先登录"}` | ✔ |
| D3 | 管理员访问管理统计 | GET /api/admin/stats（管理员 Token） | HTTP 200 + `{"code":0,"stats":{"documents":1,"chunks":7,...}}` | ✔ |
| D4 | 伪造 Token 访问 | GET /api/auth/me（Bearer bad.token.here） | HTTP 401 拒绝 | ✔ |

## 三、结论

4/4 通过。学生越权访问管理接口在业务层被拦截（统一错误码 4012），未泄露任何管理数据；伪造/缺失 Token 统一 4011。角色权限矩阵符合需求定义文档 R-07（角色与权限边界）。
