# 测试方案 · 学习支持与辅导协作智能体系统 MVP

> 文档类型：量化测试方案（正常 / 边界 / 对抗 / 权限 / 故障五类场景）
> 配套：tests/run_eval.py（30 条用例自动评测）、tests/test_core.py（单元测试）、tests/metrics/*.json（实测原始数据）

## 一、测试对象与范围

- 被测系统：MVP（src/learning_support，FastAPI + SQLite + FAISS/BM25 混合检索 + Agent 五轮循环）
- 测试入口：REST API（/api/auth/login、/api/chat SSE、/api/admin/*）与知识库检索器
- 测试方式：自动化（pytest + 评测脚本 + HTTP 端到端实测），全部结果可复现

## 三、测试环境与工具

- Python 3.11 / uvicorn / SQLite；知识库：学习支持与辅导协作管理制度（7 切片）
- 工具链：pytest 8、requests/urllib 端到端脚本、run_eval.py 评测器（规则回放模式，未配置 LLM_API_KEY 时按检索回放验证链路）
- 数据留存：tests/eval_results.json（A-D 维度逐条）、tests/metrics/*.json（F-J 维度逐条）
